# 🪨 Deepslate Client

> *A robust, privacy-first Minecraft client built for performance and community.*

---

## Project Status

**Status:** Planned  
**Expected Release:** After Atlas Client

Deepslate Client is currently in the planning phase. Development will commence following the release of Atlas Client.

---

## Project Overview

Deepslate Client is a Fabric-based Minecraft client designed as a direct alternative to **Badlion Client**. It offers the comprehensive mod ecosystem and performance tools that players expect, while eliminating the corporate data collection and advertising present in existing solutions.

The client is being developed as part of the **SunEclipseMC** initiative, with a focus on privacy, open-source transparency, and community governance.

---

## Inspiration

Deepslate Client is inspired by the functionality and breadth of the Badlion Client ecosystem:

- **Badlion Client** – Extensive mod library, server integration, and community tools.

**Built differently:**

Badlion Client, like its corporate counterparts, operates under a closed-source, data-driven business model. Deepslate Client is built to offer a similar comprehensive experience—without the tracking, data brokers, or corporate oversight.

## Planned Features

- **Comprehensive Mod Library:** Community-curated mod support.
- **Performance Optimization:** Low-latency rendering and resource management.
- **Server Integration:** Seamless server connectivity and tools.
- **Customizable HUD:** Fully configurable interface elements.
- **Clean User Interface:** Intuitive and modern design.
- **Security:** No telemetry, no analytics, no data collection.
- **Cross-Platform:** Support for Windows, macOS, and Linux.
